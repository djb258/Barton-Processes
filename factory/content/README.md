# factory/content — Content Production Silo

This silo holds content production folders that are NOT data-movement processes.
They follow Dewey numbers 1700-1799 (content production) and do not require the full 10-entry process shape.

## Contents

| Folder | Description |
|--------|-------------|
| `1700-video-ctb/` | Video CTB content — source scripts and outlines for Barton Enterprises video series |
| `1800-cf-stream-upload/` | Cloudflare Stream upload process notes |
| `brand-assets/` | Brand assets for Insurance Informatics (logos, email templates, LinkedIn) — deferred consolidation pending a future `0000-brand-assets` PROCESS-UT.md |

## Note
These folders are NOT registered in `law/process-registry.yaml` as numbered processes.
When a full UT is built for any of these, it will be numbered and moved to the appropriate silo (outreach/1700-...).
